# Contributing to Agentic Engineering Playbook

Thanks for contributing. This repository aims to be a serious open-source learning product for developers building AI agentic systems.

## What to contribute

- documentation improvements
- stronger code examples
- clearer diagrams
- missing production guidance
- project scaffolding and starter assets

## Contribution principles

- keep content practical
- favor buildable workflows over theory
- tie major concepts to project outcomes
- explain tradeoffs that matter in production

## Local setup

```bash
npm install
npm run start
npm run build
```

## Pull requests

- keep the scope focused
- describe what changed and why it helps learners
- update the sidebar when adding new docs pages
- check for broken links before merging
