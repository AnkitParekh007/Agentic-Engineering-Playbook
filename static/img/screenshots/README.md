# Screenshot Placeholders

This folder contains real launch screenshots and demo assets for the public site and README.

Recommended captures:

1. `homepage-dark.png`
   - Full homepage in dark mode
   - Desktop width around 1440px
   - Include hero, completed projects, and architecture preview sections

2. `homepage-light.png`
   - Full homepage in light mode
   - Desktop width around 1440px
   - Use the same scroll position and framing as the dark capture

3. `angular-copilot-demo.png` or `angular-copilot-demo.gif`
   - Angular Agentic Copilot UI
   - Show sidebar, chat thread, activity panel, and approval card

4. `qa-browser-report.png`
   - QA Browser Agent report or report JSON view
   - Prefer a completed safe run in `playground` or `test`

5. `project-doc-page-dark.png`
   - A representative docs page in dark mode
   - Include sidebar, markdown card, and table of contents

Capture guidance:

- Use real screenshots, not generated mockups.
- Keep browser chrome minimal and crop consistently.
- Prefer 2x retina captures if possible.
- Do not include secrets, credentials, or real production URLs.
- If a placeholder is used temporarily, label it clearly as a placeholder in the page copy.
