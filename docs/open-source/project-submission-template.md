# Project Submission Template

Use this template when proposing a new runnable project for the academy.

## Project title

Short, descriptive name:

## Problem it teaches

What AI engineering problem does this project help learners understand?

Examples:

- tool-safe enterprise automation
- retrieval quality and evals
- agent memory and session state
- observability and trace review
- generative UI or operator workflow patterns

## Why it belongs in this repo

Explain how the project strengthens the playbook:

- which layer it extends
- which learner gap it closes
- which production-grade skill it demonstrates

## Target learner

Who is this for?

- beginner AI engineer
- intermediate full-stack developer
- Angular-focused engineer
- backend/platform engineer
- enterprise architect

## Suggested stack

- language
- framework
- storage
- UI layer
- validation strategy

## Proposed deliverables

- project README
- architecture note
- starter implementation
- smoke check
- eval or deterministic test where relevant
- docs page linked from the curriculum

## Safety and scope notes

State anything sensitive up front:

- tool permissions
- environment dependencies
- browser automation risk
- third-party account requirements
- cloud cost assumptions

## Acceptance criteria

What must exist before this project should be merged?

## Portfolio value

What public proof-of-work signal would this project create for contributors or learners?
