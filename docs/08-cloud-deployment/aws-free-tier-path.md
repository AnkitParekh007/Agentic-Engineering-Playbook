# AWS Free-Tier Path

Start small and cheap.

## Phase 1

- GitHub Pages or Vercel for docs
- Render/Fly.io/Railway for backend experiments
- Supabase/Neon for Postgres

## Phase 2

- AWS ECS or Lightsail container
- RDS Postgres
- S3 for document storage
- CloudWatch logs

## Phase 3

- multi-tenant SaaS architecture
- usage billing
- organization/team model
