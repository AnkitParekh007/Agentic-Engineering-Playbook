# Example user flows

## Ask mode

1. Create a new session.
2. Choose `Ask` mode and `Mock` model.
3. Ask a question like `What is the travel meal policy?`
4. Watch the assistant stream a concise answer.
5. Inspect the right panel for planning and retrieval events.

## Plan mode

1. Switch to `Plan`.
2. Ask for a plan such as `Plan a rollout for the incident status dashboard.`
3. Review the plan-style assistant response.
4. Inspect the activity panel to see the staged execution story.

## Agent mode with approval

1. Switch environment to `prod`.
2. Choose `Agent`.
3. Submit a request like `Send a summary to leadership and request approval first.`
4. Wait for the approval card to appear.
5. Enter an approval reason and click `Approve` or `Reject`.
6. Observe the follow-up activity and final streamed response.

## Session history

1. Create multiple sessions.
2. Switch between them from the left sidebar.
3. Delete one session.
4. Refresh the page and confirm the remaining sessions persist locally.
