# Agentic Engineering Playbook

An open-source documentation and project-based learning roadmap for mastering AI agentic application development.

## Goal

Help developers become production-ready AI Agentic Engineers by building real systems:

- LLM provider gateway
- Enterprise RAG copilot
- LangGraph-style orchestrator
- MCP tool servers
- Angular agentic copilot UI
- QA browser testing agent
- Production security, evals, observability, and deployment

## Local setup

```bash
npm install
npm run start
```

## Monetization plan

The core playbook stays open-source. Monetization happens through advanced project templates, cohort learning, private community, enterprise workshops, and certification-style capstone reviews.
