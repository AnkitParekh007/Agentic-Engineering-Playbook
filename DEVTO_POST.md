# I Open-Sourced a Project-First AI Engineering Academy

Most AI learning content still leans too heavily on one-off demos, abstract tutorials, or prompt collections.

That gap is what pushed me to open-source **Agentic Engineering Playbook**.

The goal is practical: give developers a public, build-first path for learning how production-grade AI systems are assembled across backend, retrieval, orchestration, tools, UI, evals, observability, and deployment.

## What is inside

The repository is a Docusaurus curriculum plus runnable starter projects.

Current project set:

1. AI Provider Gateway
2. Enterprise RAG Copilot
3. Agent Workflow Orchestrator
4. MCP Enterprise Toolkit
5. Angular Agentic Copilot
6. QA Browser Agent

Each project teaches a different layer of real-world AI engineering:

- stable model access
- grounded retrieval
- planning and approvals
- safe tool interfaces
- operator-facing copilot UX
- browser automation with evidence capture

## Why I structured it this way

I wanted the repo to be useful to several audiences at once:

- developers learning by building
- contributors looking for meaningful open-source work
- recruiters evaluating practical AI engineering skill
- teams that want a reference curriculum for internal learning

## What makes it different

- project-first, not notes-first
- production-shaped examples instead of generic toy apps
- live docs plus runnable code
- explicit coverage of agents, copilots, RAG, MCP, evals, observability, and agentic UI

## Where I want to take it next

- more contributor-friendly chapters
- better diagrams
- more eval and observability examples
- stronger Angular and operator-UI guidance
- more community project submissions
